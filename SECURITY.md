# Reporting a security vulnerability

Please report security concerns through
[GitHub's private vulnerability reporting form](https://github.com/bavarian-studio/northmeadow/security/advisories/new).

Never report a vulnerability as a public issue. Keep the details in the private
report while we assess it and discuss disclosure with you.

## What helps

- The Northmeadow version or build number and operating system version.
- The affected feature and a description of the behaviour.
- Steps to reproduce with invented data, and what you expected instead.
- The possible impact and any workaround you have found.

Do not include customer data, note contents, names, screenshots of mandates,
passwords, recovery keys, tokens, or other secrets, even in a private report.

## What we answer

We review reports and respond in the private thread with questions, our
assessment, and next steps. If a fix is needed, we discuss it and coordinate
disclosure there.
